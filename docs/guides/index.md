# Guides

Each guide covers one task of dream_model. The examples are real files of the end-to-end app in `e2e/model_app`, or of the tests.

Start with the first one, then pick the task you have:

- [Getting started](https://hexdocs.pm/dream_model/1.0.0/guides/getting-started.html) - Write the `.sql` files of a model, generate its module, call it from a controller and check the schema at start-up.
- [Hints](https://hexdocs.pm/dream_model/1.0.0/guides/hints.html) - Every hint, with a real example and the code that it gives.
- [Why is this column Option?](https://hexdocs.pm/dream_model/1.0.0/guides/why-option.html) - Each reason the generator gives, with an example query and what to do.
- [Types](https://hexdocs.pm/dream_model/1.0.0/guides/types.html) - The Gleam type of each PostgreSQL type, exact numbers, arrays, infinity and the types that need a cast.
- [Errors](https://hexdocs.pm/dream_model/1.0.0/guides/errors.html) - The error and the exact data of each failure.
- [CI and schema drift](https://hexdocs.pm/dream_model/1.0.0/guides/ci-and-schema-drift.html) - `--check` in CI and `client.check_schema` at start-up.
- [Command reference](https://hexdocs.pm/dream_model/1.0.0/guides/command-reference.html) - Every option, setting, exit status and message.
